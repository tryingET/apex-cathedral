# Purpose

Apex Cathedral exists to provide a **local-first execution runtime for AI agents on the BEAM**.

It turns agent requests into capability-based executions over supervised resources, with **policy evaluation**, **approval gates**, and **audit events** as first-class runtime behaviors. The project is intentionally opinionated about explicit authority boundaries and avoids hidden tool access.
