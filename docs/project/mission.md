# Mission

Build and evolve a small, understandable agent runtime whose control plane stays in **Elixir/OTP**, while **TypeScript** is used for the UI, SDK, and adapter-facing surfaces.

The mission is to preserve the architecture loop captured in `docs/architecture/`, keep the execution model inspectable, and make the repository reproducible through its deterministic generator.
