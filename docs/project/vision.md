# Vision

A trustworthy local-first agent runtime where every meaningful action is **visible, policy-checked, optionally human-approved, and auditable**.

Long term, Apex Cathedral should demonstrate that capable agent systems can run on a compact BEAM-based core without hidden authority, while still offering practical operator surfaces through a gateway, SDK, and local UI.
